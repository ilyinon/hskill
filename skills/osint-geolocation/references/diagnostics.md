# Geolocation diagnostics

## Compare viewpoints

- Start with stable shapes such as road and river bends, junctions, buildings, and terrain. Search the readable names or street features first and use architectural style or vegetation to narrow an area.
- Put candidate camera positions and landmarks on the same map. Compare which landmarks lie on either side of the viewing axis. Where two positions fit the object order, use an occlusion, near/far relationship, or sightline to choose between them.
- Check whether the candidate panorama is taken from the correct side of the road or waterway. Allow for camera height, lens width, and differences between a historical scene and a recent panorama. [Bellingcat geolocation examples](https://www.bellingcat.com/resources/how-tos/2014/07/09/verification-and-geolocation-tricks-and-tips-with-google-earth/)
- Record the source and acquisition date for the image used in each comparison. Satellite layers can be mosaics with varying dates. [Google Earth imagery dates](https://support.google.com/earth/answer/6327779)

## Bound the date

Find dated evidence that puts a visible feature before or after a change. For example, a documented opening can bound a scene showing the finished structure, and a later photograph of its removal can bound the other end. State any assumptions about whether the feature is the same object and whether it could have been restored or replaced.

Use shadows only where the sun direction can be inferred from the scene and camera orientation. Perspective, slope, and local time can make several dates fit. Preserve the range the evidence supports.
